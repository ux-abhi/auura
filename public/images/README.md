# Aurra Image Assets

Place the following image files in this directory:

| Filename | Description | Used in |
|---|---|---|
| `pendant-hero.jpg` | Clean pendant on off-white background, hanging chain | Hero section, Gallery |
| `pendant-worn-dramatic.jpg` | Pendant worn on neck with blue/orange dramatic lighting | Preorder section, Gallery |
| `lifestyle-sofa.jpg` | Man sitting on sofa wearing pendant, warm ambient lighting | How It Works section, Gallery |
| `pendant-angles.jpg` | 4-panel grid showing pendant from different angles on linen | Specs section |
| `pendant-side.jpg` | Single pendant on beige surface, close-up side view | (available for future use) |

Recommended image format: JPEG at 85% quality.
Recommended dimensions: at least 1200px on the longest side.
